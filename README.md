# CricketIQ AI

An AI-powered cricket intelligence platform built using IPL ball-by-ball data.

## Project Goals

- Ball-by-ball analytics
- Player intelligence
- Team analytics
- AI-powered search
- Match prediction
- Team builder
- CricketGPT

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Next.js
- React
- Machine Learning
- LLMs
